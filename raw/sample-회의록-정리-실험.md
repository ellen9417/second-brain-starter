# (샘플 raw 자료) 회의록 정리 프롬프트 실험 메모

이 파일은 raw/ 폴더 사용법을 보여주는 가상 샘플이다. 실제 사용 시 회의록, 아티클 스크랩, 강의 노트, 업무 문서 등 무엇이든 이 폴더에 넣고 "정리해줘"라고 하면 된다. Claude는 이 폴더를 읽기만 하고 절대 수정하지 않는다.

## 실험 메모 (가상)

- 실험 1: "이 회의록 요약해줘" → 발언 순서 나열, 액션 아이템 2건 누락
- 실험 2: 출력 형식(결정/액션/맥락 3단) 지정 → 누락 0건, 다만 담당자 없는 액션이 조용히 사라짐
- 실험 3: "담당자 미정이면 '담당 미정'으로 표기" 추가 → 누락 0건 + 미정 항목 2건 표면화
- 결론: 형식 강제 + 빈 값 명시 강제가 핵심
